# HealthGPT AI 🩺🤖

> **Your Intelligent Healthcare Companion**

HealthGPT AI is a full-stack healthcare assistance platform that combines **machine learning, OCR, and generative AI** to help users understand health information and navigate toward appropriate healthcare resources.

> **Important:** HealthGPT is an informational assistance application. It does not provide a medical diagnosis or replace qualified healthcare professionals.

---

# 🚀 Features

## 🩺 Symptom Checker

Users can select symptoms and receive a ranked list of **candidate conditions** generated by the trained machine-learning model.

The system:

1. Validates selected symptoms.
2. Converts them into the model's feature representation.
3. Runs the trained classification model.
4. Calculates class probabilities.
5. Returns the top candidate conditions.
6. Provides a confidence/caution indicator.

The application presents these as **candidate conditions rather than confirmed diagnoses**.

---

## 📄 Medical Report OCR

Users can upload supported blood-report images.

HealthGPT uses:

- **Tesseract OCR**
- **pytesseract**
- A custom blood-report parser

Pipeline:

```text
Image
  ↓
OCR
  ↓
Extracted text
  ↓
Report parser
  ↓
Structured laboratory values
```

Example:

```json
{
  "test": "hemoglobin",
  "value": 15.0,
  "result": "15",
  "unit": "g%",
  "reference_range": "14 - 16"
}
```

The OCR service is CPU-based and does not require GPU inference.

---

## 🤖 AI-Powered Report Explanation

After laboratory values are extracted, HealthGPT can use the **Google Gemini API** to generate an understandable explanation of the report.

The goal is to make technical laboratory information easier to understand while maintaining appropriate safety boundaries.

---

## 💬 AI Health Assistant

HealthGPT provides conversational AI assistance for health-related questions.

The backend communicates with the generative-AI service so API credentials do not need to be exposed in the frontend.

---

## 🏥 Healthcare Discovery

The platform can help users discover healthcare facilities using location-based services, providing a practical next step when professional evaluation may be needed.

# 🧠 Machine Learning

The current symptom-prediction system uses a trained **Logistic Regression** classifier.

Production model files:

```text
backend_models/
└── disease_prediction/
    ├── logistic_regression.joblib
    └── label_encoder.joblib
```

The model receives a binary feature vector representing the selected symptoms and returns class probabilities used to rank candidate conditions.

### Confidence policy

HealthGPT uses an engineering-level confidence policy to communicate uncertainty. A result can be flagged when the top model score is low or when the difference between the top two predictions is small.

These thresholds are **not medically validated diagnostic thresholds**.

# 🌐 API Overview

The backend exposes versioned REST APIs under:

```text
/api/v1
```

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/api/v1/health` | API health check |
| `POST` | `/api/v1/auth/login` | User authentication |
| `GET` | `/api/v1/auth/me` | Current authenticated user |
| `GET` | `/api/v1/symptoms` | Available symptoms |
| `POST` | `/api/v1/predictions/disease` | Symptom-based candidate prediction |

# 🩺 Medical Safety

HealthGPT provides **informational assistance**, not medical diagnosis or treatment.

The symptom checker provides **candidate conditions** based on selected symptoms. Model scores are engineering outputs and should not be interpreted as clinical probabilities or medical certainty.

OCR can also produce errors depending on image quality, layout, fonts, tables, and scanning conditions.

Users should consult qualified healthcare professionals for diagnosis, treatment, urgent symptoms, and medical decisions.
